## 🎯 Assignment

### 1. Responsive Dashboard

Recreate the responsive layout of a dashboard, representing the control panel of a hypothetical web application, following the provided reference screenshots.

The layout must be built using **Bootstrap 5**.

Keep the official Bootstrap documentation at hand to make proper use of the framework's main features. Components, helper classes and utilities may also come in handy.

### 2. Add a New Page with a Form

Add a new page to the dashboard, following the provided reference screenshots.

Build the page using HTML forms and input elements styled with **Bootstrap 5**.

Keep the official documentation at hand to make proper use of the framework's features, including components, helper classes and utilities.

In particular:

- Review the Bootstrap grid system to arrange form fields according to the design and ensure they display correctly on both desktop and mobile devices.
- Use margin and padding utilities to manage spacing.

**Remember:** `form` tags and input fields are HTML elements. Bootstrap helps us style them more easily through its classes!

### 💡 Suggestions & Notes

Bootstrap provides many ready-made components that can be used as they are (**as-is**) or with some customization.

Some components have already been covered in class, while others can be found in the official framework documentation.

Whenever you want to use a Bootstrap component:

1. Test it in a separate file first.
2. Copy the example code from the official documentation.
3. Observe how it behaves and make sure it works as expected.
4. Only then integrate it into your layout.

Following this approach will help keep the amount of custom CSS code relatively small.
